02 // WRITINGS
TECHNICAL DISPATCH · CLOUD-NATIVE RUNTIME SECURITY · FORTHCOMING

Container at War: Distroless is Not Enough

Runtime exploit mechanics, Linux LSM boundary enforcement, and defense-in-depth

Stripping away /bin/sh, curl, and package managers shrinks container attack surface, but it cannot prevent exploitation when application vulnerabilities exist. When an interpreter or compiled binary processes untrusted input, an attacker operates directly inside the process memory space. This dispatch explores how Linux Kernel Security Modules—specifically AppArmor LSM and Seccomp-BPF syscall filters—confine malicious execution even when an application is fully compromised.
