About & Principles

04 // COLOPHON

Programmo da quando i monitor pesavano venti chili. Ho costruito la mia carriera partendo dall'ecosistema Linux e dal web moderno, focalizzandomi negli anni su Node.js, TypeScript, Go e sicurezza del kernel Linux.

«La semplicità non è l'assenza di complessità, ma la sua risoluzione rigorosa.»

Oggi mi divido tra la progettazione di sistemi backend resilienti, la didattica (insegno sviluppo e architetture software) e la ricerca applicata: come rendere gli agenti AI davvero utili ai developer su compiti concreti e verificabili, senza fuffa.

CONTAINER ATTACK SURFACE

┌─────────────────────────────────┐ │ USER SPACE APPLICATION │ │ Node.js / Go / Distroless │ ├─────────────────────────────────┤ │ ▲ System Call Interface (libc) │ ├─────────────────────────────────┤ │ SECCOMP-BPF FILTER │ │ [Allowlist: read, write, exit] │ │ [Block: ptrace, execveat...] │ ├─────────────────────────────────┤ │ APPARMOR LSM POLICY │ │ [Deny /etc/shadow, deny caps] │ ├─────────────────────────────────┤ │ LINUX KERNEL CORE │ │ Namespaces & Cgroups │ └─────────────────────────────────┘

Rappresentazione del modello a cipolla difensivo: anche se il runtime applicativo è compromesso, i filtri Seccomp e il modulo LSM (AppArmor) impediscono l'escalation dei privilegi nel kernel.
